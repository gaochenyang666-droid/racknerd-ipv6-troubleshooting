# IPv6 修复后的维护与后续验收

本项目在 2026 年 10 月 17 日时已通过 Mac + Hysteria 2 over IPv6 的真实业务验收，但仍有几个应明确保留的待办。

## 1. iPhone / Shadowrocket

- [ ] Wi-Fi 下确认网络具有可用的 IPv6 出口。
- [ ] 用服务器 IPv6 入口连接 Hysteria 2，确认握手和代理请求成功。
- [ ] 切换蜂窝数据复测 IPv6 可达性及节点连接。
- [ ] 分别检查 Google、YouTube、Telegram 访问。
- [ ] 检查原有国内直连、国外代理分流规则是否保持正确。
- [ ] 确认断开节点后不会把预期的敏感流量意外直连。

说明：部分 Wi-Fi、企业网络和蜂窝运营商对 IPv6 的支持存在差异。客户端能打开一个 IPv6 网站，并不等于目标 UDP 端口或 QUIC 一定可用。

## 2. TLS 证书自动续期

- [x] 已完成一次强制续期、部署、重启及复测。
- [x] 本轮证书有效期延长至 2027 年 1 月。
- [ ] 记录自动续期任务实际运行位置与触发方式。
- [ ] 确认断开 Mac 本地隧道后，续期任务是否仍有可用的 Let's Encrypt API 路径。
- [ ] 确认服务器端新证书部署、服务热重载或重启流程无人值守。
- [ ] 设置到期前提醒，并定期核实证书剩余有效期。

提醒：一次人工强制续期成功，并不能等价于无人值守续期已通过验收。避免将密钥放进公开仓库。
